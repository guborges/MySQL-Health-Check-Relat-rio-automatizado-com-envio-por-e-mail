# MySQL-Health-Check-Relat-rio-automatizado-com-envio-por-e-mail
Script Bash que coleta métricas de saúde de um servidor MySQL, gera um relatório HTML visual e envia automaticamente por e-mail usando o **sendEmail** (Perl).  Criado para ambientes corporativos onde não é possível instalar ferramentas como postfix, mailx ou sendmail.
